# Pontuações oficiais das missões — BIOGLOW

A tabela abaixo consolida as pontuações apresentadas no vídeo oficial de referência [1]. Os valores indicados como “por unidade” dependem da quantidade de objetos que cumprem a condição.

## Pontuação das missões

| Missão | Condição de pontuação | Pontos |
|---|---|---:|
| **Inspeção de equipamento** | Equipamento em apenas uma área de lançamento | **20** |
| **01 — Levantamento por Drone** | Drone não toca mais o tapete | **20** |
|  | Bônus: mapa LiDAR virado com marcador na área de pesquisa | **+10** |
| **02 — Sementes Explosivas** | Cada semente que não toca mais o caule | **10 por semente** |
| **03 — Virar a Rocha** | Bandeira de pesquisa abaixada | **20** |
|  | Bônus: rocha retornada à posição inicial | **+10** |
| **04 — Folhas da Sorte** | Uma folha removida sem tocar o ninho | **10** |
|  | Segunda folha removida e Esperança na posição inicial | **+20** |
|  | Terceira folha removida | **10** |
|  | Esperança retornada ao habitat de folhas, se tiver sido removida | **10** |
| **05 — Raízes Alcançáveis** | Raiz parcialmente estendida | **10** |
|  | Raiz completamente estendida | **20** |
| **06 — Frenesi das Formigas Cortadeiras** | Formiga tocando o ninho | **10** |
|  | Cada fragmento de folha contido no ninho | **10 por fragmento** |
| **07 — Fungo Gigantesco** | Micélio completamente estendido | **20** |
|  | Bônus: conexão entre o micélio de uma equipe e a raiz da equipe adversária | **+10** |
| **08 — Emaranhado** | Vinha tocando o tapete | **30** |
| **09 — Plataforma de Pesquisa** | Plataforma de pesquisa elevada | **10** |
|  | Armadilha fotográfica implantada | **10** |
|  | Semente que não toca mais a árvore | **10** |
| **10 — Microhabitats Frágeis** | Habitat da aranha na posição inicial | **10** |
|  | Habitat do caracol na posição inicial | **10** |
| **11 — Janela para o Passado** | Cobertura da raiz abaixada, tocando o tapete | **20** |
| **12 — Ancião da Floresta** | Bengala completamente elevada, tocando a árvore | **20** |
|  | Laço de suporte ao redor do poste | **10** |
| **13 — Espécies-Chave** | Espécie-chave na plataforma de restauração e árvores jovens elevadas | **30** |
| **14 — Sementes de Renovação** | Cada semente contida na estação de replantio | **5 por semente** |
|  | Bônus: cada semente tocando o tapete na estação | **+5 por semente** |
| **15 — Arquitetura Biocêntrica** | Dossel de aninhamento elevado | **10** |
|  | Claraboia do jardim completamente inserida | **10** |
|  | Escotilha de compostagem aberta, tocando o tapete | **10** |
|  | Bônus ambiental, conforme a doca: Fazenda, Mina ou Cidade | **+10** |
